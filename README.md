# Iceland Models — V2

This version follows the structure of the reference Wix site more closely: full-screen welcome hero, Our Models gallery, All About Us section, quote section, Get in Touch form, Book Online page, Blog page and black/white footer.

## Run
npm install
npm run dev

## Vercel
Import the project into Vercel from GitHub. No special build command is needed; Vercel detects Next.js.

## Replace sample content
- `public/logo-white.png` and `public/logo-black.png` contain the supplied Iceland Models logo.
- Replace the sample Unsplash image URLs in `app/page.js` with your model photos.
- Change email/phone in `app/page.js` and `app/book-online/page.js`.
